# הלוח שלי — גרסה 2.0.0

לוח משימות אישי בעברית: React → Nginx → FastAPI → PostgreSQL.

## הפעלה ב-Windows
1. יש להתקין ולהפעיל Docker Desktop במצב Linux containers.
2. חלצי את התיקייה ופתחי בה PowerShell.
3. הריצי `powershell -ExecutionPolicy Bypass -File .\start.ps1`.
4. פתחי http://localhost:8095. הבנייה הראשונה דורשת אינטרנט להורדת החבילות והתמונות.

ל-Linux/macOS: צרי `.env` ובו `DB_PASSWORD=` עם סיסמה אקראית ארוכה (אותיות ומספרים), ואז `docker compose up -d --build`.

## מה כלול
- יצירה, עריכה ומחיקה של משימות, תיאור, פרויקט, עדיפות ותאריך יעד.
- שלוש עמודות: לביצוע, בתהליך והושלם. העברה באמצעות בחירת סטטוס.
- חיפוש וסינון לפי פרויקט, עדיפות ומשימות באיחור.
- יצוא JSON ויבוא גיבוי. יבוא **מוסיף** עותקים ואינו מוחק משימות קיימות.
- מסך שגיאה ברור כשהשרת אינו זמין, ללא הצגת נתונים מדומים.
- שמירה במסד נתונים עם volume קבוע. הפעלה מחדש אינה מוחקת מידע.

## ניהול
עצירה: `docker compose stop`
הפעלה: `docker compose up -d`
לוגים: `docker compose logs --tail=100`
עדכון לאחר שינוי קוד: `docker compose up -d --build`
אין להריץ `docker compose down -v` אלא אם רוצים למחוק לצמיתות את כל הנתונים.
מומלץ להוריד גיבוי דרך כפתור הגיבוי באופן קבוע.

## תחום שימוש
גרסה אישית למחשב המקומי, ללא משתמשים או כניסה. הפורט נחשף רק למחשב המקומי; מסד הנתונים והשרת אינם מפרסמים פורטים. לפני חשיפה לרשת יש להוסיף אימות ו-HTTPS. אחרי הבנייה ניתן לעבוד ללא אינטרנט כל עוד Docker פועל. זו תוכנת דפדפן מקומית ולא קובץ EXE.

## פיתוח ובדיקות
שרת: `pip install -r server/requirements.txt` ואז `uvicorn app.main:app --app-dir server` (משתמש ב-SQLite מקומי כשאין DATABASE_URL).
ממשק: מתוך client הריצי `npm ci` ואז `npm run dev`; לשימוש API בפיתוח יש להשתמש בשער Nginx או להגדיר proxy מקומי.
בדיקות: `pip install pytest httpx` ואז `python -m pytest tests -q`.
סכמת מסד הנתונים נוצרת בהפעלה הראשונה. לשינויי סכמה עתידיים יש להוסיף מיגרציות Alembic; create_all אינו משנה טבלאות קיימות.

## NetFree / SSL בבנייה
סקריפט start.ps1 מאתר תעודות ציבוריות של NetFree במאגרי Root ו-CA של Windows ומעתיק אותן לבנייה של השרת והממשק. אימות SSL נשאר פעיל. לא מועתקים מפתחות פרטיים. קובצי התעודה המקומיים מוחרגים מ-Git.
אם אין זיהוי אוטומטי, שמרי תעודת CA בפורמט PEM בשם `netfree.crt` בשתי התיקיות `server/certs` ו-`client/certs`, והריצי שוב את הסקריפט. ניתן לקבל את התעודה המותקנת ממנהל התעודות של Windows.
לאחר עדכון: `git pull --ff-only` ואז `powershell -ExecutionPolicy Bypass -File .\start.ps1`.

## גרסה 2.0 — סביבת עבודה מלאה
- תתי־משימות עם סימון השלמה; גרירה בין עמודות וסידור, כולל חלופה בחצים למקלדת ולנייד.
- היום שלי, תצוגות יום/שבוע/חודש ומסכי פרויקט עם אחוז התקדמות.
- חזרה יומית/שבועית/חודשית לפי הלוח הלועזי. המופע הבא נוצר רק בהשלמת הנוכחי. תאריך עברי משמש להצגה ולבחירה.
- היסטוריית יצירה, עדכון, מחיקה ושחזור. מחיקה מעבירה לסל מחזור ואינה מוחקת לצמיתות.
- תזכורות בתאריך נבחר, כבויות כברירת מחדל; העדפה מקומית בדפדפן. פועלות רק כשהלוח פתוח, ללא שירות רקע או מייל.
- עדכון מסד הנתונים מוסיף רק טבלאות task_details ו-task_history ומשאיר את tasks הקיימת ללא שינוי. מומלץ לבצע גיבוי לפני העדכון.
- גיבוי JSON בגרסה 2 כולל את פרטי המשימות הפעילות החדשים. קובצי גרסה 1 נתמכים ביבוא. היסטוריה וסל מחזור אינם כלולים בייצוא JSON; לשמירתם יש לגבות את מסד PostgreSQL כולו.
